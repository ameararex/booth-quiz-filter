# 画像・デザイン・共有

更新日: 2026-10-27。

実BOOTHの公開HTMLから取得した booth.pximg.net のサムネイルURLを、外部imgとしてローカルで表示確認した。画像ファイルは保存・プロキシ配信しない。URLホストとパスを検証し、CSPも同ホストに限定する。遅延読み込み・no-referrer・失敗時の代替表示を用意した。BOOTHの画像なし用プレースホルダーは画像欠損として扱う。

[取得方針](https://booth.pm/announcements/863)を画像の包括的な転載許諾とは扱わない。[ガイドライン](https://booth.pm/guidelines)・[関連規約](https://policies.pixiv.net/)と外部表示条件の確認、削除連絡先の整備は公開前に必要。関連規約ページは調査時に取得できず、確認済みとはしない。

承認された白と明るい青、M PLUS Rounded 1c（ローカル配信、ライセンス同梱）、四分割/三本線の切り替えをReactへ反映。一覧は小画像→店名→商品名→価格→ショップ非表示。商品非表示は撤去した。HTMLモックは架空8商品の歴史的な比較用で、現行機能をすべて反映した仕様書ではない。

共有は100〜200ショップの利用を想定し、Hono + D1で短いURLを発行する方式を採用。URLへのリスト埋め込みは使わない。[期限・無料枠・利用例](sharing-budget.md)を参照。JSONバックアップは継続する。
