## 現在の作業

- 了承されたHTMLモックのデザインをReact版（`/`）へ反映済み。白＋明るい青、M PLUS Rounded 1c、仮表紙、四分割/三本線アイコンを採用。
- 一覧は小さい画像→店名→商品名→価格→ショップ非表示の細い1行。長い名前は省略記号で表示。商品非表示は画像表示の「…」内へ移した。

- 実データでの人気順は取得元にある順序・指標を検証してから対応する。独自の売上や人気度は推定しない。
- デザイン見直し用のHTMLモックを追加。`/mockups/catalog.html` で表紙中心の画像表示・一覧表示・非表示と解除を試せる。商品・SVG表紙は架空で、非表示設定は保存しない。
- デザインの方向性は決定済み。実画像の取得・表示条件、URL共有方式は引き続き未決定。
- Gitをmainで初期化し、originに https://github.com/ameararex/booth-quiz-filter.git を登録済み。リモートは初期化時点で空。
- 初回コミット `bd4cff3` をGitHubの `main` にpush済み。
- React + TypeScript + Viteによる架空データの試作品を実装済み。
- 検索、商品/ショップ非表示、解除、localStorage保存、JSON移行、読み込み/失敗表示を対象にする。
- 実データ収集、Hono、D1、Cloudflareへの公開は今回の初期作業では実装しない。
