# 技術構成

更新日: 2026-10-27。Cloudflareには未公開。

| 用途 | 採用 |
| --- | --- |
| UI | React + TypeScript + Vite + CSS。SSRなし |
| 商品配信 | Workers Static Assetsの事前生成JSON |
| 検索・ショップ非表示 | ブラウザ内で処理 |
| 個人設定 | localStorage、JSONバックアップ |
| 商品収集 | 管理用Node.js + cheerio。UIから収集しない |
| URL共有API | Workers上のHono、/api/* のみ実行 |
| 共有保存 | D1。商品DBや自動同期とは分離 |

共有URLはリスト本体を埋め込まず、24文字のランダムIDを渡す。コピーを7日間保存し、取得側はプレビュー後に追加/置換する。認証・自動同期・アカウント登録は導入していない。共有URLを知る人は内容を取得できる。削除用秘密鍵は別に保管する。

通常閲覧は静的配信で、全パスのrun_worker_firstは設定しない。D1の全件検索は行わず、共有IDの主キー検索と期限の索引を利用する。商品収集・大きなHTML解析はWorkerに持ち込まない。ORM、KV、R2、Queues、外部CIは必要としない。

収集は5つのBOOTH公式ソートの各順序を保持し、別の順序の取得結果を混ぜて順位を推定しない。全ページ成功してからmanifestを切り替える。部分取得・失敗と正常更新日時を区別する。
