# UI用フォント

M PLUS Rounded 1c のMedium (500) / Bold (700)を使用。

- 配布元: Fontsource `@fontsource/m-plus-rounded-1c` 5.3.0
- 紹介: https://fontsource.org/fonts/m-plus-rounded-1c
- japaneseサブセットのWOFF2を無改変で同梱し、ファイル名のみ変更。
- ライセンス: SIL Open Font License 1.1。同梱の `LICENSE` を参照。
- ローカル配信のため、閲覧時にGoogle Fonts等へ通信しない。
- 合計約1.9MB。採用時は必要な文字範囲の分割等で配信量を見直す。
