# BOOTHクイズ検索（仮）

BOOTHのクイズに関する商品を、自分の好みに合わせて探すための非公式検索補助サイトです。

現在は**架空の8商品を使う試作品**です。BOOTHからの商品取得・画像転載・実商品の購入リンク・アカウント登録・端末間の自動同期は実装していません。

## ローカルで起動する

Node.js 24.13以上とnpmを使用します。

```powershell
npm ci
npm run dev
```

表示されたローカルURLを開いてください。通常は http://127.0.0.1:5173 です。

```powershell
npm run check          # データ処理のテスト、型チェック、本番ビルド
npm run preview        # 本番ビルドのローカル確認
npm run deploy:check   # 本番ビルドとWranglerのドライラン（公開しない）
```

`npm run deploy` はCloudflareへの公開操作です。アカウント・無料プラン・公開対象を確認してから実行します。今回の初期作業では公開しません。

## 試せること

デザイン見直し用の [HTMLモック](public/mockups/catalog.html) はローカル起動後の `/mockups/catalog.html` で開けます。仮表紙付きの商品一覧、検索、画像/一覧切り替え、非表示と解除を試せます。商品・画像は架空で、モックの設定は保存されません。URL共有ボタンは配置案のみです。検討内容は [docs/sharing-and-thumbnails.md](docs/sharing-and-thumbnails.md) を参照してください。

- 商品名・ショップ名の検索。NFKC正規化、英字の大小の同一視、空白区切りのAND検索。
- 明るい配色・丸ゴシック・仮表紙付きの画像表示と、細い一覧表示。新着順/人気順は操作確認用の仮の順序です。
- 商品・ショップ単位の非表示、一覧からの解除。ショップを隠すと、そのショップの商品がまとめて非表示になります。
- 通常の操作はショップ非表示が中心で、商品単位の非表示は画像表示の「…」にあります。
- localStorageへの保存。保存失敗の表示と、破損データを自動で上書きしない回復操作。
- JSONの書き出し・取り込み。内容と件数の確認、ID重複除去、追加/置換の選択。初期選択は追加です。
- 読み込み中、検索結果なし、取得失敗と再読み込み。

非表示は個人の好みであり、商品の品質評価ではありません。BOOTH公式の非表示リストとは独立しています。localStorageは端末・ブラウザ間で自動同期されず、データ消去等で失われる場合があります。固定の200件制限はありませんが、保存容量は有限です。

## 非表示JSONの形式

```json
{
  "version": 1,
  "items": [{ "id": "sample-item-001", "name": "商品名" }],
  "shops": [{ "id": "sample-shop-a", "name": "ショップ名" }]
}
```

IDは英数字・ハイフン・アンダースコアの1〜128文字、名前は空白だけを除く1〜500文字です。取り込みファイルは2MiB以下に制限します。これは処理容量の制限で、200件上限ではありません。サンプルのIDは架空の識別子であり、実データ用のショップ識別子の安定性はまだ検証していません。

## 構成

- `src/App.tsx`: 検索画面、非表示管理、インポート確認。
- `src/components/`: 商品表示と画像/一覧の切り替え。
- `src/lib/`: 商品データ検証・検索・非表示リスト処理とテスト。
- `src/hooks/useHiddenList.ts`: 保存・回復処理。
- `public/data/`: サンプルの商品JSONとmanifest。
- `public/sample-covers/`、`public/fonts/`: 仮表紙とローカル配信の丸ゴシック（ライセンス同梱）。実商品の画像は含みません。
- `wrangler.jsonc`: Workers Static Assetsの設定。Workerスクリプト・D1は使いません。

通常の閲覧でBOOTH・D1・動的APIへアクセスしません。HTTP APIが必要になったらHono、商品データの差分管理が必要になったらD1を検討します。
